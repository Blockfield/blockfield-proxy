# Blockfield/blockfield-proxy v2.54.1

## Кратко

Первый релиз прокси из собственного репозитория. Образ переезжает из `ghcr.io/netherg-io/blockfield-proxy` в
`ghcr.io/blockfield/blockfield-proxy`, а деплой идёт через webhook Dokploy по точному digest с автоматическим
откатом. Исходники прокси те же, что в работающем образе v2.54.0.

## Для игроков

Изменений для игроков нет. Подтверждение: исходники плагина, `velocity.toml`, лобби, патчи Limbo и `start-proxy.sh` побайтно
совпадают с `proxy/` в `netherg-io/blockfield-modpack` на теге v2.54.0, из которого собран работающий образ
(сверка файлов по git-хешам). В `distribution/Dockerfile.proxy` изменилась только метка `org.opencontainers.image.source`.
Деплой прокси обрывает текущие подключения: после него нужно войти заново.

## Технические изменения

- Образ публикуется как `ghcr.io/blockfield/blockfield-proxy:<тег>` сборкой на теге `v*` в этом репозитории
  (история `proxy/` выделена из `netherg-io/blockfield-modpack`, лицензия — #1).
- GitHub Release версии с `release-notes.md`; файл проверяется до публикации образа (#2, #3).
- Deploy proxy: канал `:prod` переставляется на digest тега и вызывается webhook Dokploy; API-ключа Dokploy в Actions
  нет (#4). Ошибка docker печатает ответ registry (#5). Успех — только когда swarm закрыл окно мониторинга
  обновления (#6); лимиты: 20 мин до healthy, затем Monitor сервиса + 5 мин (#8). При ошибке — откат на digest,
  работавший до деплоя.
- CI на pull request собирает образ с допустимым тегом `pr-<номер>` (#7).
- Пересборка тянет текущие `itzg/mc-proxy:java21` и `maven:3.9-eclipse-temurin-21` (не закреплены по digest).
  Velocity 3.5.1 (build 615), Limbo `29571119` с патчами и voicechat-velocity 2.6.18 закреплены и не менялись.

## Обновлённые компоненты

Пины не изменились относительно предыдущего релиза (mods/\*.pw.toml, resources.lock.json).

## Совместимость и необходимые действия

Клиент, сервер и лаунчер обновлять не нужно, вайпа нет. Протокол, авторизация Drasl, gate `pack_version` и лобби не
менялись. Deploy proxy запускается вручную, когда в игре никого нет.

## Известные проблемы

Базовые образы не закреплены по digest, поэтому пересборка того же тега может отличаться слоями базового образа.
